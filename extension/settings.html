Set up the local companion

From the ThunderQuail repository, install dependencies once and start the companion:

python -m pip install -r companion/requirements.txt
python -m companion

Wait for Index ready and leave that terminal open. In a second terminal in the same directory, run python -m companion --show-token. Paste the token below, set the URL to http://127.0.0.1:49371, and save settings.

On later runs, use python -m companion. It reuses the token and index. If it can’t choose your profile, run python -m companion --profile "path-to-your-profile" with the folder shown in Thunderbird’s Help → Troubleshooting Information → Profile Folder.

Use the token from python -m companion --show-token. Leave it blank to disable indexed search. Increase this if searching a large index needs more time. Chat continues without indexed results after this timeout. The companion runs its Hugging Face embedding model locally.
