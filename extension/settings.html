Download and set up the companion
  1. Open the latest ThunderQuail release, download Source code (zip) under Assets, and extract it. If you already have the repository, use your checkout.
  2. Install 64-bit Python 3.12 if you need Python. Open PowerShell or a terminal in the extracted folder that contains companion/requirements.txt. Use python3 in place of python if that is your system’s command.
  3. Install the dependencies once, then start the companion. 
    python -m pip install -r companion/requirements.txt
python -m companion
    The first run downloads the embedding model and indexes locally cached MBOX mail. Wait for Index ready and leave the terminal open.
  4. In a second terminal in the same folder, run python -m companion --show-token. Paste the token below and use http://127.0.0.1:49371 as the URL. Click Test companion connection, then Save settings.

On later runs, use python -m companion from the same folder. It reuses your token and index. Press Ctrl+C in its terminal to stop it.

If the companion can’t choose your Thunderbird profile, open Help → Troubleshooting Information → Profile Folder in Thunderbird and use that folder’s path with python -m companion --profile "path-to-your-profile". If your index is stored in a custom directory, add --db-dir "path-to-your-index" each time.

Get the token with python -m companion --show-token. Leave it blank to disable indexed search.
