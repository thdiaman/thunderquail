ThunderQuail

Chat, draft email, and review proposed mailbox actions from Thunderbird 128 or later.

Install from GitHub

  1. Download the GitHub XPI.
  2. In Thunderbird, open Add-ons and Themes → Extensions. From the gear menu, choose Install Add-on From File and select the downloaded XPI.
  3. Review the requested permissions and confirm the installation.

Thunderbird checks GitHub for future updates to this build.

Install from Add-ons for Thunderbird

Find ThunderQuail on Add-ons for Thunderbird. Once the listing is available, use its Add to Thunderbird download and install the XPI using the same gear menu. Thunderbird checks the directory for future updates to this build.

Switch update channels

Get a version newer than the one you have installed from the channel you want to use. Install that XPI directly over your current copy using Install Add-on From File. Leave the existing add-on installed to preserve your settings. Future automatic updates follow the channel of the newly installed package.

If both channels currently offer the same version as your installed copy, wait for a newer release on your target channel.
